# Code de conduite

Rationarium s'inspire du [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## Ce qu'on attend

- Être respectueux, y compris en désaccord.
- Critiquer le code et les idées, jamais les personnes.
- Accueillir les nouveaux venus et les questions simples.
- Reconnaître ses erreurs et en tirer les leçons.

## Ce qui n'est pas accepté

- Le harcèlement, public ou privé.
- Les propos ou images à caractère sexuel, discriminatoire ou insultant.
- La publication d'informations privées d'autrui sans son accord.
- Tout comportement qu'on ne jugerait pas acceptable dans un cadre professionnel.

## Portée et application

Ce code s'applique aux issues, demandes de fusion, discussions et à tout échange au nom du
projet. Pour signaler un comportement, utilisez le signalement privé de GitHub sur le dépôt ou
contactez le mainteneur depuis son profil GitHub. Les signalements sont traités avec discrétion.

Le mainteneur peut modifier ou retirer une contribution, ou exclure temporairement ou
définitivement une personne dont le comportement contrevient à ce code.
